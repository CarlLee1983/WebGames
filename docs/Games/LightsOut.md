# Lights Out：Midnight Power Lab（熄燈遊戲）

## 遊戲目標

重新佈線午夜電網，讓所有亮起的節點熄滅。每次操作會同時切換選定節點與它上、下、左、右的狀態；對角線不受影響。

## 電網尺寸

| 模式 | 尺寸 | 特色 |
| --- | ---: | --- |
| Relay | 3 × 3 | 適合熟悉十字切換規則 |
| Grid | 5 × 5 | 標準 Lights Out 挑戰 |
| Network | 7 × 7 | 更大的搜尋空間與更長解法 |

每一局由合法節點操作產生，因此保證存在解法。切換模式或 New 會重新產生電網，步數、時間、提示與 Undo 歷史同時歸零。

## 回合與目標步數

1. 第一次切換節點後開始計時。
2. 每次切換計為一步，影響範圍會在滑鼠懸停或鍵盤聚焦時預覽。
3. Undo 會反向套用最近一次操作並減少一步；暫停或完成後不能 Undo。
4. Hint 會從目前棋盤的一組有效解法中標示下一個節點，並累計提示次數。
5. Target 是產生本局時求得的有效解法步數，可作為效率基準；玩家仍可能找到同樣短或更短的等價解。
6. 所有燈熄滅後停止計時，顯示星級、步數、提示數與最佳紀錄。

## 評級與紀錄

- 未使用提示且步數不超過 Target：三星。
- 最多使用兩次提示，且步數不超過 Target + 3：二星。
- 其他完成局：一星。
- Relay、Grid、Network 的最佳步數分開儲存在瀏覽器 Local Storage。

## 控制方式

| 操作 | 滑鼠／觸控 | 鍵盤 |
| --- | --- | --- |
| 選擇節點 | 點擊或輕點 | 方向鍵移動單一棋盤焦點 |
| 切換十字電路 | 點擊節點 | <kbd>Enter</kbd> 或 <kbd>Space</kbd> |
| 移到同列首尾 | — | <kbd>Home</kbd> / <kbd>End</kbd> |
| 提示 | Hint | <kbd>H</kbd> |
| 復原 | Undo | <kbd>U</kbd> |
| 暫停／繼續 | Pause / Resume | <kbd>P</kbd> 或 <kbd>Esc</kbd> |
| 新電網 | New | <kbd>R</kbd> |

視窗失焦或切換分頁時，進行中的遊戲會自動暫停。尚未操作第一步或已完成時，Pause 不會啟用。

## 畫面與無障礙回饋

- 進度條顯示已熄滅節點比例，資訊卡同步顯示步數、亮燈數、時間與最佳步數。
- 聚焦或懸停節點會標出受影響的十字範圍；Hint 以脈衝外框標示建議位置。
- 棋盤只保留一個 Tab 停靠點，再以方向鍵移動，避免 Tab 依序穿越最多 49 個節點。
- 讀屏會得知列、欄與節點目前是 on 或 off，操作結果也會透過狀態訊息播報。
- 暫停遮罩會封住棋盤；完成遮罩提供星級、Target、最佳紀錄與重新開始入口。

## 策略提示

1. 同一節點切換兩次會抵銷，因此一組解法中每個節點只需要考慮按或不按。
2. 可從第一列開始推導：為了熄滅上一列，只能操作其正下方節點。
3. 使用 Undo 比直接重新開局更適合比較不同分支。
4. 若要挑戰三星，先觀察 Target，再把 Hint 留給真的卡住時。

## 技術與驗證

- 產生器以合法操作洗牌，求解器使用 GF(2) 高斯消去法，支援 3×3、5×5、7×7。
- 棋盤、階段、歷史、步數、提示、計時、Target 與訊息集中在不可變純狀態模型。
- 自動測試涵蓋影響範圍、不可變切換、三種尺寸求解、可玩生成、Undo、提示、暫停計時、完成評級、紀錄清洗與文字棋盤。
- `window.render_game_to_text()` 提供階段、亮燈數、Target、紀錄、評級與逐列棋盤狀態，供自動檢查使用。

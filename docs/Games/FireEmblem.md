# Fire Emblem

Fire Emblem 是一場固定 8×8 地圖的單關戰棋。玩家指揮 Lord、Cavalier 與 Archer，利用不同移動力、射程與地形，擊敗三名敵軍中的 Dread Lord；Lord 陣亡則戰敗。

## 操作

| 操作 | 滑鼠／觸控 | 鍵盤 |
| --- | --- | --- |
| 選擇盟軍 | 點擊棋盤單位或盟軍快速選取卡 | 聚焦棋盤後移動游標並按 `Enter` |
| 移動／攻擊 | 點擊藍色移動格或紅色敵軍 | 方向鍵移動游標，`Enter` 執行 |
| 等待 | `Wait` | `W` |
| 結束玩家階段 | `End Phase` | `E` |
| 暫停／繼續 | `Pause`／`Resume` | `P` |
| 重新開始 | `Restart`／結果對話框 | `R` |
| 全螢幕 | `Fullscreen` | `F`，`Esc` 離開 |

Canvas 可接收鍵盤焦點，黃色框表示鍵盤游標。觸控玩家可以用快速選取卡切換盟軍，再直接點選目標格。

## 單位與戰鬥

- Lord：20 HP、移動 5、近戰射程 1；必須存活。
- Cavalier：24 HP、移動 6、近戰射程 1；高防禦與機動力。
- Archer：16 HP、移動 5、射程 2–3；不能在相鄰格反擊。
- 攻擊傷害為攻擊力減去防禦與地形防禦，最低 1 點。
- 防守方存活且攻擊者位於其射程內時會反擊。
- 所有盟軍行動完成或玩家主動結束階段後，敵軍依序移動與攻擊。

## 戰術情報

- 玩家階段會以深紅色角標標出敵軍的威脅範圍；範圍包含敵軍本回合可到達位置與其後可攻擊的格子。
- 盟軍移動後若有敵人在射程內，棋盤資訊板與頁面會先顯示戰鬥預測，包括造成傷害、目標剩餘 HP、是否遭反擊及攻擊者剩餘 HP。
- 藍色格代表可移動位置，玫紅色目標代表目前可以攻擊；戰場上方圖例會同時說明三種標記。

## 地形

- 平地、堡壘與王座消耗 1 點移動力。
- 森林消耗 2 點移動力並提供 1 點防禦。
- 堡壘提供 2 點防禦，王座提供 3 點防禦。
- 城牆不可通行；單位也不能穿過或停在其他存活單位的位置。

## 顯示與可及性

- 桌面版依視窗高度縮放，使 1280×720 能在首屏看完整棋盤。
- 390×844 使用可橫向平移的 720px 戰術畫布，64px 邏輯格會顯示為 48px，避免縮成難以觸控的小格。
- 所有主要按鈕至少 48px 高；當前階段、回合、訊息、盟軍 HP、敵方威脅與戰鬥預測也以 DOM 文字呈現。
- 開始、暫停、勝利與失敗都有可朗讀的對話框；暫停會凍結敵軍計時。
- Canvas 像素比例最高 2 倍，避免超高 DPI 裝置建立過大的緩衝區。

## 驗證

`utils.test.ts` 覆蓋開局、地形移動成本、阻擋、移動、戰鬥預測、敵方威脅區、攻擊與反擊、等待、敵軍階段、勝利及重開。頁面另以桌面與手機視窗實測戰術交戰、預測結果、暫停／恢復與響應式戰場。

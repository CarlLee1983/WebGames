# Battleship Blitz

Battleship Blitz 是一款直向無盡街機射擊遊戲。玩家駕駛戰機穿過逐波加強的敵軍，累積連擊、拾取武器升級，並在每五波迎戰一艘母艦 Boss。任務面板會持續顯示戰場威脅、下一次 Boss 接觸、飛行員階級與本機最高分。

## 操作

| 操作 | 鍵盤 | 觸控 |
| --- | --- | --- |
| 移動 | `WASD` 或方向鍵 | 在畫布上拖曳，或使用方向按鈕 |
| 射擊 | 按住 `Space` | 在畫布上拖曳時自動射擊，或按住「Hold to fire」 |
| 開始／重新挑戰 | `Space` | 「Start sortie」／「Try again」 |
| 暫停／繼續 | `P` | 「Pause」／「Resume」 |

畫布可以用鍵盤聚焦；頁面上方的狀態列會同步顯示模式、分數、波次、機體耐久、剩餘生命與目前武器。開始、射擊與觸控方向鍵會和畫布一起出現在手機首屏，不必先捲動到遊戲下方。

## 任務情報

- Mission cadence 以五段航線顯示目前位於哪一波，第五段固定為母艦 Boss。
- Threat 會依場上敵機、敵方彈幕與 Boss 狀態在 `Clear`、`Engaged`、`Critical`、`Boss` 間變化。
- 飛行員階級依分數由 `Cadet`、`Wingman`、`Ace` 提升至 `Legend`。
- Best 會把最高分保存在目前瀏覽器；重新挑戰或重開頁面後仍可查看。

## 核心規則

- 每局從 3 條生命、100 點機體耐久與 1 級 Blaster 開始。
- 受到子彈或敵艦碰撞會扣除耐久，並獲得短暫無敵時間。
- 耐久歸零會失去一條生命；仍有生命時會回到畫面下方並恢復耐久。
- 擊破敵人會增加分數與連擊。受傷或進入下一波時，連擊會重設。
- 一般波次持續派出敵機；清除該波後進入下一波。
- 第 5、10、15……波為 Boss 波。擊破母艦後才會推進波次。
- 三條生命全部耗盡後，戰場模擬會凍結，直到玩家選擇重新挑戰。

## 敵軍

| 類型 | 特性 |
| --- | --- |
| Interceptor | 基礎耐久與直線射擊 |
| Stalker | 高速下壓並左右蛇行 |
| Dreadnought | 較高耐久，體型更大 |
| Alien Mothership | 高耐久、多套彈幕模式，每五波出現 |

## 道具與武器

敵人有機率掉落道具，Boss 會掉落多個道具。

| 標記 | 效果 |
| --- | --- |
| H | 回復 30 點耐久，不超過上限 |
| 盾牌 | 5 秒無敵 |
| B | Blaster：正面多軌光彈 |
| M | Missile：多枚追蹤飛彈 |
| L | Laser：高速穿透雷射 |
| S | Spread：扇形散射 |

撿到與目前相同的武器會升級一級，最高 5 級；切換到不同武器時會保留至少 1 級，並降低一級作為換裝成本。

## 戰術提示

- 觸控拖曳會把戰機保持在手指上方，避免手指遮住機體。
- 優先清除高速 Stalker，避免下半場被夾擊。
- 高連擊會提高擊破分數，但一次受傷就會歸零。
- 盾牌的五秒無敵很適合穿越 Boss 的密集彈幕。
- Boss 的攻擊模式會輪替；先觀察彈幕，再尋找安全縫隙。

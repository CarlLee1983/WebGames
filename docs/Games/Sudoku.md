# Sudoku：Logic Atelier（數獨）

## 遊戲目標

完成 9×9 邏輯手稿，使每一列、每一欄與每個 3×3 宮都恰好包含數字 1–9。題目中的角落圓點代表不可修改的初始線索。

## 難度

| 模式 | 初始線索 | 空格數 | 適合情境 |
| --- | ---: | ---: | --- |
| Calm | 42 | 39 | 暖身與熟悉候選數 |
| Focus | 36 | 45 | 標準解題節奏 |
| Master | 30 | 51 | 需要更長推理鏈 |

題目由已知唯一解的基礎題進行合法數字、列與欄轉換，因此每局都有唯一解。切換難度或 New puzzle 會產生新題並清除計時、筆記、提示與 Undo 歷史。

## 輸入與回合規則

1. 選擇任一格後，可用數字盤或鍵盤輸入 1–9；第一次輸入、筆記或提示會開始計時。
2. 錯誤數字會以紅色與驚嘆號標出，Conflicts 同步顯示目前衝突格數。
3. Notes 模式只能在空格加入或移除候選數，不會增加正式步數。
4. 填入正確數字後，同列、同欄與同宮的相同候選筆記會自動移除。
5. Undo 可還原最近一次正式輸入或筆記操作；暫停或完成後不能 Undo。
6. Hint 優先修正目前選取的錯誤／空白格，否則尋找下一個未完成格；提示會計為一步並累計使用次數。
7. 完成全部 39、45 或 51 個空格後停止計時並顯示結果。

## 評級與紀錄

- 未使用提示，且步數不超過空格數：三星。
- 最多使用三次提示，且步數不超過空格數 + 9：二星。
- 其他完成局：一星。
- Calm、Focus、Master 的最佳步數分開儲存在瀏覽器 Local Storage。

## 控制方式

| 操作 | 滑鼠／觸控 | 鍵盤 |
| --- | --- | --- |
| 選擇格子 | 點擊或輕點 | 方向鍵移動單一棋盤焦點 |
| 移到同列首尾 | — | <kbd>Home</kbd> / <kbd>End</kbd> |
| 輸入數字 | 數字盤 | <kbd>1</kbd>–<kbd>9</kbd> |
| 清除 | 橡皮擦 | <kbd>Backspace</kbd> / <kbd>Delete</kbd> |
| 候選筆記 | Notes | <kbd>N</kbd> |
| 提示 | Hint | <kbd>H</kbd> |
| 復原 | Undo | <kbd>U</kbd> |
| 暫停／繼續 | Pause / Resume | <kbd>P</kbd> 或 <kbd>Esc</kbd> |
| 新題目 | New puzzle | <kbd>R</kbd> |

視窗失焦或切換分頁時，進行中的題目會自動暫停。尚未輸入任何內容或完成後，Pause 不會啟用。

## 畫面與無障礙回饋

- 完整 9×9 棋盤會直接縮放到手機寬度，不需要在棋盤內左右滑動。
- 聚焦格子的同列、同欄與同宮會淡色標示，相同數字使用另一種色彩標示。
- 進度條與資訊卡顯示完成比例、時間、步數、衝突與最佳步數。
- 棋盤只保留一個 Tab 停靠點，再以方向鍵移動，避免 Tab 依序穿越 81 格。
- 讀屏會得知列、欄、given／editable、數值、候選筆記與 conflict 狀態。
- 暫停遮罩隱藏題目；完成遮罩顯示星級、步數、時間、提示與最佳紀錄。

## 解題策略

1. 先找只有一個候選數的格子，再檢查列、欄或宮中只剩單一位置的數字。
2. 使用 Notes 保存候選集合，避免靠猜測覆寫正確推理。
3. Conflicts 出現時可先 Undo，比繼續沿錯誤分支更有效率。
4. 若要挑戰三星，Hint 應保留到真正無法推進時。

## 技術與驗證

- 生成器保留唯一解，支援固定 seed 以重現測試題。
- 題目、答案、輸入、筆記、歷史、選取格、階段、提示、計時與訊息集中在不可變純狀態模型。
- 自動測試涵蓋三種難度唯一解、候選數、衝突、筆記、錯誤輸入、Undo、提示、完美完成、暫停計時、評級、紀錄清洗與文字棋盤。
- `window.render_game_to_text()` 提供階段、完成度、衝突、選取格、評級與逐列棋盤，供自動檢查使用。

# Tetris Arcade（俄羅斯方塊）

## 遊戲目標

操控七種方塊完成橫列、累積分數並盡可能延長遊戲。棋盤使用可預測的 7-bag 出塊機制；每袋都會把 I、J、L、O、S、T、Z 各一個方塊打亂後提供，降低長時間拿不到關鍵方塊的運氣落差。

## 核心規則

1. 方塊從棋盤頂端生成，可左右移動、旋轉、柔降或硬降。
2. 填滿一整列後，該列消除，上方方塊下移。
3. 每消除 10 列升一級；等級越高，自動下落速度越快。
4. 新方塊在出生位置無法放置時，遊戲結束。
5. Hold 每個方塊只能使用一次；目前方塊鎖定後才可再次交換。
6. Ghost Piece 會顯示目前方塊硬降後的位置。

## 計分

| 行為 | 分數 |
| --- | ---: |
| 柔降 | 每格 1 分 |
| 硬降 | 每格 2 分 |
| Single | 100 × 等級 |
| Double | 300 × 等級 |
| Triple | 500 × 等級 |
| Tetris（四列） | 800 × 等級 |
| Combo | （目前 Combo − 1）× 50 × 等級 |
| Perfect Clear | 額外 1200 × 等級 |

連續放置且每次都有消行時，Combo 會逐次增加；任何一次沒有消行的放置都會把目前 Combo 歸零，但 Best Combo 仍會保留到本局結束。畫面上的消行訊息會保留約 1.3 秒，顯示該次事件與獲得分數。

## 控制方式

| 操作 | 鍵盤 |
| --- | --- |
| 開始／新一局 | <kbd>Enter</kbd> |
| 左右移動 | <kbd>←</kbd> / <kbd>→</kbd> |
| 順時針旋轉 | <kbd>↑</kbd> / <kbd>X</kbd> |
| 逆時針旋轉 | <kbd>Z</kbd> / <kbd>B</kbd> |
| 柔降 | <kbd>↓</kbd> |
| 硬降 | <kbd>Space</kbd> |
| Hold | <kbd>C</kbd> / <kbd>A</kbd> / <kbd>Shift</kbd> |
| 暫停／繼續 | <kbd>P</kbd> / <kbd>Esc</kbd> |
| 重新開始 | <kbd>R</kbd> |
| 全螢幕 | <kbd>F</kbd> |

手機與觸控裝置可使用畫面旁的 Hold、旋轉、硬降、左右移動及柔降按鈕。尚未開始、暫停或遊戲結束時，無效的玩法按鈕會停用。切換分頁、視窗失焦或裝置暫時離開遊戲時，進行中的對局會自動暫停。

## 狀態提示

- 狀態卡會顯示目前遊戲模式、下一級仍需消除的列數與進度條。
- Board Stable、High Stack、Critical Stack 表示堆疊高度；警告與危險狀態也會在棋盤外框顯色。
- 外部資訊面板同步顯示 Score、Level、Lines、Combo、Best Combo 與已放置方塊數。
- Canvas 支援鍵盤焦點並提供動態無障礙描述。

## 策略提示

1. 優先維持平坦表面，避免製造只能用特定方塊填補的深洞。
2. 使用 Hold 保留 I 方塊，準備一次消除四列。
3. 留意下一個方塊與 Ghost Piece，硬降前先確認落點。
4. Combo 不限定每次消除幾列；穩定連續清除通常比等待高風險大招更安全。
5. 進入 High Stack 後先降低高度，不要為 Perfect Clear 或 Tetris 冒險封死入口。

## 技術與驗證

- 遊戲為純瀏覽器 Client Component，符合靜態匯出限制。
- 方塊旋轉使用 SRS wall kick 表，I 方塊與其他方塊採用各自的位移表。
- 遊戲狀態與畫布更新分離，並提供可重現的時間推進與文字狀態介面。
- 純邏輯測試涵蓋 7-bag、開始／暫停、移動、旋轉、Hold、硬降、Top Out、Combo、Perfect Clear、提示生命週期、等級進度與危險高度。

# Kids Stair Rush（小朋友下樓梯）

Kids Stair Rush 是一款向下探索的 Canvas 生存動作遊戲。玩家控制角色左右移動，在不斷上升的階梯間尋找下一個落點，避開天花板與危險踏板，挑戰更深樓層。

## 核心目標

- 持續向下落到下一塊踏板，避免從畫面底部掉出。
- 避免被上方天花板尖刺追上。
- 維持體力並刷新本機最高樓層紀錄。
- 連續落在非尖刺踏板上可累積落地連段；受到尖刺傷害時連段會歸零。

## 踏板種類

| 顏色 | 種類 | 效果 |
| --- | --- | --- |
| 綠色 | 安全踏板 | 第一次落地恢復 1 點體力，最多 10 點 |
| 銀色 | 尖刺踏板 | 扣除 5 點體力並中斷落地連段 |
| 黃色 | 彈簧踏板 | 立即將角色向上彈起，必須準備下一次落點 |
| 藍色 | 輸送帶 | 恢復 1 點體力，同時持續將角色推向箭頭方向 |
| 粉色 | 崩落踏板 | 落地後開始碎裂，約半秒後失去支撐 |

角色撞到天花板尖刺會扣除 3 點體力並被往下推。受傷後有短暫保護時間，不會在同一瞬間連續扣血。

## 控制方式

| 操作 | 鍵盤 | 觸控 |
| --- | --- | --- |
| 向左移動 | `←` / `A` | 按住左移按鈕，或按住遊戲畫面左半部 |
| 向右移動 | `→` / `D` | 按住右移按鈕，或按住遊戲畫面右半部 |
| 開始／重新挑戰 | `Space` | 開始遊戲／重新挑戰按鈕，或點一下遊戲畫面 |
| 暫停／繼續 | `Space` / `P` | 暫停遊戲／繼續遊戲按鈕 |

切換到其他視窗時，遊戲會自動暫停並清除持續移動輸入，避免角色在背景中失控。

## 難度與進度

每下降 120 像素會增加一個地下樓層。深度越高時，踏板會逐步變窄、捲動速度也會提高：

| 樓層 | 捲動速度 |
| --- | --- |
| B0–B9 | 60 px/s |
| B10–B29 | 80 px/s |
| B30–B49 | 100 px/s |
| B50–B99 | 120 px/s |
| B100 之後 | 由 150 px/s 繼續增加，最高 250 px/s |

速度階段只會在真正改變節奏的 B10、B30、B50、B100 與達到上限的 B200 顯示提示，不會在速度未變時誤報加速。機台資訊列會顯示目前速度、距離下一個主要速度階段的樓層數與進度條。

遊戲也會分析角色下方最近一塊仍可使用的踏板，顯示其種類以及應往左、往右或維持方向。崩落完成的粉色踏板不會被列為可用落點；這項提示是視覺輔助，仍需玩家根據實際速度做最後修正。

## 策略提示

1. 先觀察踏板顏色，再決定落點；綠色踏板最適合恢復節奏。
2. 角色落下時只做小幅修正，長時間按住方向容易越過窄踏板。
3. 踩到輸送帶時提早反向修正，避免被推離邊緣。
4. 粉色踏板只提供短暫支撐，落地後立刻規劃下一步。
5. 彈簧踏板可能把角色送向天花板，體力較低時應保留安全距離。

## 技術與驗證

- 遊戲狀態與繪製皆在瀏覽器端執行，符合靜態匯出限制。
- 高分保存在瀏覽器 `localStorage` 的 `nsShaftHighScore`。
- `render_game_to_text()` 提供模式、角色位置、速度階段、下一次加速距離、事件有效期與最近落點方向；`advanceTime(ms)` 可推進規則時間供煙霧測試使用。
- `src/app/games/kids-stair-rush/utils.test.ts` 覆蓋初始狀態、高分解析、真實速度門檻、落點預測、平台生成、輸入／暫停、安全落地、尖刺與崩落踏板規則。

## 健康提示

兒童遊玩時建議由照顧者陪同，並定期休息、保持舒適距離與良好坐姿。

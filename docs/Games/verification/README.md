# 品質驗證紀錄

本目錄保存各遊戲依[遊戲質感與 UX 基準](../QualityBaseline.md)執行的驗證證據。驗證紀錄是品質結果的權威來源；registry 只保存最新完成紀錄的摘要。

## 路徑與命名

每次驗證新增一份文件：

```text
docs/Games/verification/<slug>/<YYYY-MM-DD>-v<版本>.md
```

同一遊戲同一天重跑時，在日期後加入序號，例如 `2026-07-26-2-v1.md`。不要覆寫舊紀錄；若舊紀錄有錯，新增勘誤並連回原紀錄。

從 [TEMPLATE.md](./TEMPLATE.md) 複製新紀錄。檔案狀態可為：

- `draft`：檢查尚未完成，不得更新 registry。
- `passed`：所有項目皆為 `pass` 或有理由的 `n/a`。
- `failed`：至少一項為 `fail`。

最新完成的 `passed` 或 `failed` 紀錄支配 registry 摘要。即使同版本曾經通過，較新的失敗紀錄仍取代舊結果。

## 受驗證修訂

`revision` 指向接受驗證的遊戲實作 Git revision。驗證紀錄本身可以在下一個 commit 加入。若該 revision 之後出現可能影響玩法、輸入、版面、素材、無障礙或建置結果的變更，原紀錄應視為待重新驗證。

## 驗證者

只列出實際執行檢查的人或代理。自動檢查、桌面試玩與行動版試玩可由不同驗證者負責，但每項證據都必須能看出由誰完成。

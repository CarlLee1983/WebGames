# Zookeeper（動物園連鎖）

Zookeeper 是一款單人相鄰連鎖益智遊戲。玩家在 6×6 棋盤上拖曳相同動物，串起至少三隻相鄰動物來得分，目標是用更少步數達到 1500 分並取得最佳 Safari 評級。

## 核心規則

1. 每條連鎖只能包含同一種動物。
2. 下一隻動物必須與上一隻上下或左右相鄰；斜角不算相鄰。
3. 同一格不能在一條連鎖中重複使用。
4. 至少連接三隻才會消除；拖回前一格可以回退目前路徑。
5. 消除後，上方動物會落下並由新動物補滿棋盤。
6. 若棋盤沒有任何三連鎖，系統會自動洗牌，直到重新出現有效操作。
7. 達到 1500 分後該局立即完成並顯示評級，需開始新 Safari 才能繼續。

遊戲沒有倒數時間或步數上限；步數會影響最終評級。

## 計分

分數採用長連鎖獎勵：`長度² × 20 + 超過三隻的數量 × 30`。

| 連鎖長度 | 分數 |
| --- | ---: |
| 3 | 180 |
| 4 | 350 |
| 5 | 560 |
| 6 | 810 |

更長的連鎖能顯著減少達標所需步數。

## Safari 評級

| 評級 | 條件 |
| --- | --- |
| Gold | 4 步內完成，且未使用提示 |
| Silver | 7 步內完成，最多使用 1 次提示 |
| Bronze | 其他完成方式 |

## 控制方式

| 操作 | 滑鼠／觸控 | 鍵盤 |
| --- | --- | --- |
| 開始／新 Safari | Start Safari／New Safari 按鈕 | `Space` / `Enter` |
| 建立連鎖 | 從第一隻動物拖過相鄰同類動物 | — |
| 顯示提示 | Hint 按鈕 | `H` |
| 重新開始 | Restart 按鈕 | `R` |
| 全螢幕 | Fullscreen 按鈕 | `F` |
| 離開全螢幕 | Exit Fullscreen 按鈕 | `Esc` |

提示會以黃色虛線標出一條可行的三連鎖，但仍需由玩家親自拖曳完成。使用提示會列入結算評級。
同一條提示仍在棋盤上時再次按 Hint，只會重新顯示說明，不會重複增加提示次數；開始描繪任一新路徑後，提示才算離開棋盤。

## 畫面資訊

- Canvas 內顯示目前分數、1500 分目標與棋盤。
- Canvas 下緣會即時計算目前路徑可獲得的分數，並顯示仍可爭取的 Gold／Silver／Bronze 評級。
- 畫面右側同步顯示目標進度、剩餘分數、步數、目前連鎖價值、評級展望、最佳連鎖、提示次數、有效群組及洗牌次數。
- 完成後會顯示最終分數、步數、最佳連鎖、提示用量及 Gold／Silver／Bronze 評級。

## 策略提示

1. 優先尋找四隻以上的路徑，長連鎖的分數成長遠高於三連鎖。
2. 拖錯時直接退回前一格，不必放開後重新開始。
3. 觀察消除後的落下方向，嘗試讓同類動物在同一欄相遇。
4. 只有卡住時才使用提示；想取得 Gold 評級不能使用提示。
5. 自動洗牌不會扣分，但會記錄在本局統計中。

## 技術與驗證

- 遊戲狀態、隨機種子、重力與洗牌都在瀏覽器端執行，符合靜態匯出限制。
- `render_game_to_text()` 提供棋盤、選擇路徑、預估分數、剩餘目標、提示、評級展望與結算狀態；`advanceTime(ms)` 可推進訊息計時。
- `src/app/games/zookeeper/utils.test.ts` 覆蓋棋盤生成、路徑合法性、連鎖預估、提示去重、拖曳回退、重力、消除、結算鎖定與評級規則。

# Monopoly

Monopoly 是一款雙人輪流進行的地產競賽。玩家擲兩顆骰子沿 24 格棋盤前進，購買無主地產、向對手收租，並處理機會、命運、稅務、監獄與免費停車事件。最後仍未破產的玩家獲勝。

## 操作

| 操作 | 滑鼠／觸控 | 鍵盤 |
| --- | --- | --- |
| 擲骰 | 頂部「擲骰」 | `D` 或空白鍵 |
| 購買／跳過 | 購地對話框或頂部按鈕 | `B`／`N` |
| 確認事件 | 事件對話框「繼續」 | `Enter` |
| 暫停／繼續 | 頂部「暫停／繼續」 | `P` |
| 全螢幕 | 頂部「全螢幕」 | `F`，`Esc` 離開 |
| 重新開始 | 頂部「重開」或結果對話框 | `R` |

不適用於當前階段的擲骰、購買與跳過按鈕會停用，避免誤觸。暫停會凍結擲骰、移動動畫與事件倒數；重新開始會同時解除暫停。

## 規則與節奏

- 兩位玩家各從 `$1500` 開始，輪流擲兩顆六面骰。
- 經過起點可獲得 `$200`。
- 無主地產與車站可選擇購買；停在對手持有的地產時支付標示租金。
- 購地決策會列出買後現金、單次租金與租金率；資金不足時直接顯示差額，不會提供無法完成的購買操作。
- 機會、命運、稅務、監獄與免費停車事件會調整金額或位置，短事件在 0.9 秒後自動推進，也可立即確認。
- 資金跌破零時玩家破產，名下地產會釋出；只剩一名未破產玩家時顯示結果。
- 骰子序列使用固定種子，方便重現與測試；重開會回到相同初始狀態。

## 顯示與可及性

- 棋盤使用最高 2 倍裝置像素比例繪製，在高 DPI 螢幕保持清晰。
- 桌面版會依視窗高度限制棋盤尺寸，1280×720 可在首屏看完整棋盤；390×844 不會產生橫向溢出。
- Canvas 提供當前玩家、位置、金額與狀態的可讀名稱；購地、事件、暫停與結果使用原生 DOM 對話框。
- 玩家卡會列出持有地產、各地租金與目前租金池，方便比較雙方版圖。
- 購地主要操作會自動取得焦點，按鈕可由鍵盤操作，主要觸控控制高度至少 48px。

## 驗證

`utils.test.ts` 覆蓋初始棋盤、固定骰子、事件自動推進、購地試算、資金不足、購買、跳過、經過起點獎金、重開與文字狀態輸出。頁面另以桌面與手機視窗實測擲骰、暫停／恢復與購地流程。

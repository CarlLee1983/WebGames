# Puzzle Bobble

## 遊戲目標

從發射台射出彩色泡泡，連接至少三顆同色泡泡使其消除。失去天花板支撐的泡泡會一併掉落；清空全部泡泡即可過關，泡泡越過底部危險線則結束本局。

## 核心規則

- 棋盤使用 11 欄交錯六角網格，奇數列為 10 欄。
- 每六次射擊後，天花板會加入一整列新泡泡並向下推進。
- 畫面會以 `Stable ceiling`、`Pressure building`、`Critical depth` 顯示目前深度壓力。
- 下一顆泡泡只會從目前棋盤仍存在的顏色中抽取；棋盤清空後即完成關卡。
- 六種泡泡同時使用顏色與不同符號，辨識不只依賴色彩。

## 計分與紀錄

- 同色消除：每顆 10 分。
- 懸空掉落：每顆 20 分。
- 連續成功消除會累積 Chain；第二次起每層連擊增加 15 分。
- 未形成三顆連線時，Chain 會歸零。
- 最高分保存在瀏覽器 `localStorage`，重新載入後仍會顯示。

## 操作

### 指標與觸控

- 在棋盤內拖曳可調整瞄準方向，放開即射擊。
- 棋盤下方提供 `Left`、`Shoot`、`Right` 三個 48px 高按鈕，手機不必依賴精細拖曳。
- 瞄準導引線會顯示碰牆反彈路徑。

### 鍵盤

| 按鍵 | 功能 |
|---|---|
| `A` / `←` | 向左微調 |
| `D` / `→` | 向右微調 |
| `Space` / `Enter` | 射擊 |
| `P` / `Esc` | 暫停／繼續 |
| `R` | 重新開始 |
| `M` | 音效開關 |

## 回饋與暫停

- 成功消除會顯示得分增量、粒子、震動與音效；懸空泡泡有獨立掉落效果。
- 每次射擊都更新距離下一次天花板推進的次數，並透過 live status 回報結果。
- 視窗失焦或頁面切到背景時會自動暫停，避免飛行中的泡泡在玩家看不到時繼續移動。
- 暫停、勝利與失敗皆有完整遮罩與明確的繼續／重開操作。

## 響應式與可及性

- 390 × 844 手機版會在首屏排列標題、主要控制、四項統計、完整棋盤與觸控射擊列，無水平捲動。
- 1280 × 720 桌面版將棋盤置於左欄，標題與說明置於右欄，避免大型標題把棋盤推到首屏之外。
- 所有主要按鈕至少 48px 高，保留可見焦點環與可存取名稱。
- Canvas 使用裝置像素倍率繪製，最高限制為 2 倍，兼顧清晰度與效能。
- `window.render_game_to_text()` 可輸出階段、分數、連擊、壓力、目前／下一顏色及文字棋盤，供檢查工具讀取。

# Deep Sea Penguin

Deep Sea Penguin 是一款無盡下潛閃避遊戲。玩家控制企鵝在海流中左右移動，收集金色魚群、避開危險生物，並挑戰更深的水域。

## 操作

| 操作 | 滑鼠／觸控 | 鍵盤 |
| --- | --- | --- |
| 左右移動 | 在水域中拖曳，或按住左右控制鈕 | 聚焦畫布後使用方向鍵或 `A` / `D` |
| 暫停／繼續 | 中央 Pause／Resume 控制鈕 | `P` |
| 開始／重玩 | 畫面上的 Start Dive／Dive Again | — |

遊戲載入後會停在準備畫面，不會在玩家閱讀規則時偷偷增加深度。暫停會凍結深度、敵人、魚與背景海流。

## 目標與難度

- 深度是主要生存成績；魚數是額外收集成績。
- 每次碰到危險生物會失去一顆心；三顆心用盡時結束本次下潛。
- 受傷後有 1 秒無敵時間，避免重疊碰撞瞬間扣除所有生命。
- 深度超過 500、1,000 與 2,000 公尺時，海流分別進入第 2、3、4 級。
- 海流提升時，移動速度與生成頻率逐步加快；生成間隔設有下限。
- 500 公尺後開始出現河豚，1,200 公尺後開始出現海膽。

右側的洋流壓力條會顯示目前流速倍率、距離下一次加速還有多少公尺，以及下一種即將加入的危險生物。受傷時水域底部會顯示 Recovery shield 與剩餘保護時間；收集魚時則會顯示 Golden fish +1。暫停會連同這些回饋計時一起凍結，因此恢復遊戲後不會平白失去保護時間。

## 可及性與行動裝置

- Pixi 畫布可以接收鍵盤焦點，並提供完整操作名稱。
- 頁面另有至少 56px 高的左右與暫停控制，支援觸控按住移動。
- HUD 在窄螢幕使用緊湊三欄排版，不會超出視窗。
- 遊戲狀態透過 live region 宣告；生命值也有可讀文字，不只依賴愛心圖示。
- 受傷與收集事件有獨立文字回饋，洋流壓力條也提供標準 `progressbar` 語意。

## 可檢查狀態

頁面提供 `window.render_game_to_text()`，回傳目前模式、深度、魚數、生命、洋流等級與進度、企鵝水平位置、畫面內魚與危險數量，以及受傷保護剩餘時間。這讓瀏覽器煙霧測試不必只依賴 Pixi 畫面像素。

## 生命週期

每次下潛都有獨立的 Pixi controller。重新開始或離開頁面時會移除 ticker、畫布與所有指標／鍵盤監聽器；非同步初始化若在頁面卸載後才完成，也會立即銷毀，不會留下背景遊戲。
